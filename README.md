# zangetsu-shell

A Unix shell being built from scratch in C++.

## Features (currently)

- **REPL Interface:** 
- **Builtin Commands:** Native implementations of `exit`, `echo`, `type`, and `pwd`.
- **Executable Resolution:** Traverses the system `$PATH` to locate and execute external programs.
- **Child Process Spawning:** Executes child processes with argument forwarding.
